# CrowdCounter AI 👥📸

A lightweight, client-side web application that automatically detects and counts people in group photos using AI, wrapped in an elegant and modern user interface.

Built with HTML5, CSS3, JavaScript, and powered by [face-api.js](https://github.com/vladmandic/face-api). No backend server or paid API keys required!

---

## ✨ Features

* **Instant Face Detection:** Automatically identifies and counts human faces in any uploaded group image.
* **Visual Overlays:** Draws stylish bounding boxes with serial numbers over each detected person directly on the photo.
* **Drag & Drop Support:** Easily drag and drop images or browse files from your device.
* **Responsive & Elegant UI:** Designed with modern gradients, clean typography, smooth transitions, and custom loader animations.
* **100% Client-Side:** All processing happens directly inside your web browser for complete privacy.
